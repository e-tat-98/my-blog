## 🛠 Product

完成した Web アプリがこちら👇️

> <https://stock-mate-sigma.vercel.app>

### 1) 📦 在庫一覧画面

![在庫一覧画面](/images/posts/stock-mate/stock-list.jpg)

**■ UI・UX**

ホーム画面です。登録した在庫を一覧で確認できます。
カゴアイコンで買い物リストに追加、ゴミ箱アイコンで在庫一覧から削除できます。
±アイコンで在庫数もすぐに増減できます😁

**■ こだわりポイント**

検索窓はインクリメンタルサーチにしました🔍️
（ただ、漢字で登録したアイテムはひらがなで検索してもヒットしないので、ここは改良したい…）

### 2) ➕️ 在庫登録画面

![在庫登録画面](/images/posts/stock-mate/stock-register.jpg)

**■ UI・UX**

在庫を登録する画面です。カテゴリは自由に登録できます。

**■ こだわりポイント**

「常備品」として登録したアイテムは、在庫一覧で「−」を押して在庫数が 0 になると、自動で買い物リストに追加されます📥

### 3) 🛒 買い物リスト画面

![買い物リスト画面](/images/posts/stock-mate/shopping-list.jpg)

**■ UI・UX**

お買い物のお供に！！
これで買い忘れはなくなります😇

**■ こだわりポイント**

在庫一覧から買い物リストに追加したアイテムは、チェックを付けると自動で在庫数が +1 されます。
買い物から帰ってきて、いちいち在庫数を増やす手間がなくなりました！

## 👨🏻‍🎓 What I learned

### Prisma

Prisma は初めて使いました。フロントエンド出身で SQL には慣れていなかったので、SQL を直接書かずに DB を操作できるのはありがたく、DB 周りの理解のハードルが下がった気がします。
ただ、スキーマを TypeScript ではなく Prisma 独自の書き方（`.prisma` ファイル）で定義するのが、最初はちょっと馴染めなかったです…笑
SQL 自体ももっと理解したいので、次はスキーマを TypeScript で書けて SQL に近い感覚で使える Drizzle も試してみたいです🤔

### SpecKit（AI 駆動開発）

SpecKit、恐るべし！！アプリ開発にかかった時間はトータルで6時間ほどでした。

ただ、落とし穴も多かったです。
たとえば仕様に「ログイン認証を行う」と書いたところ、最初にできあがったものはログインはできるのに、ログアウトの導線がありませんでした。

AI に明確に指示を出すこと、設計をしっかり固めることは、引き続き人間の仕事なんだと体感しました。
また、細かいコードの理解が追いついていない部分もあったので、AI に作業させたあとにコードを読んで勉強することの大切さも実感しました。

### Vercel

Vercel はやっぱり簡単で良いです。ホスティングからデータベースの構築まで、ほとんど詰まることなく設定できました。
ただ、勉強という点では物足りなかったです…笑
